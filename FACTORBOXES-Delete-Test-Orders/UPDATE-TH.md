# เพิ่มปุ่มลบออเดอร์ทดลอง — FACTORBOXES

สำหรับชุด GitHub / Vercel / Supabase ที่ส่งให้ในบทสนทนานี้
ไฟล์นี้ยังไม่ได้อัปเดตเว็บบน Vercel ต้องอัปโหลดไฟล์ใน ZIP ไป GitHub ก่อน

## อัปเดต

1. แตก ZIP
2. เปิด repository ของเว็บที่เชื่อม Vercel (จากข้อมูลก่อนหน้า: Factorboxes/web-app)
3. อัปโหลดโฟลเดอร์ app ใน ZIP ลงหน้าแรก repository ให้รวมกับ app เดิม ไม่สร้าง app/app
4. มีไฟล์ใหม่ app/api/delete-order/route.ts และ app/admin/delete-order.tsx
5. แทนที่ app/admin/order-documents.tsx ด้วยไฟล์ในชุดนี้
6. Commit changes แล้วรอ Vercel Deploy สำเร็จ จากนั้นรีเฟรชเว็บ

ไม่ต้องรัน SQL ไม่ต้องสร้างฐานข้อมูลใหม่ และไม่ต้องเปลี่ยน Environment Variables
ไม่ต้องแทนที่โฟลเดอร์ lib หรือไฟล์ล็อกอิน/สลิปที่แก้ภายหลัง

ถ้า order-documents.tsx ของคุณเคยแก้เพิ่มเติม ให้เก็บการแก้นั้นไว้แล้วเพิ่มเพียง:
- import DeleteOrder from './delete-order';
- ใส่ <DeleteOrder key={orderId} orderId={orderId}/> ท้าย section ของ component

## วิธีใช้

เข้าสู่ระบบด้วยบัญชีเจ้าของร้าน > หลังบ้าน > คำสั่งซื้อ > จัดการออเดอร์
เลื่อนลงใต้ส่วนพิมพ์เอกสาร > ลบออเดอร์นี้
พิมพ์เลขออเดอร์ที่แสดง เช่น FB-12345678 แล้วกดยืนยันลบถาวร
ระบบโหลดหน้าใหม่เมื่อสำเร็จเพื่อให้เห็นยอดล่าสุด

เจ้าของร้าน (บัญชี ADMIN_EMAIL) เท่านั้นที่ลบได้
ลบแล้วออเดอร์จะหายจากประวัติของลูกค้าและหลังบ้าน ลิงก์ติดตามเดิมจะไม่พบออเดอร์
เอกสารใบเสร็จ/ใบกำกับและรายการสลิปของออเดอร์ถูกลบด้วย ภาพสลิปจะถูกลบจาก Storage
ยอดขายและ VAT ที่นับจากออเดอร์นั้นจะหายไปจากรายงานทุกช่วงเวลา
สินค้า สมาชิก รูปสินค้า และออเดอร์อื่นไม่ถูกลบ
ไม่สามารถกู้คืนผ่านหน้าเว็บได้ จึงควรใช้กับออเดอร์ทดลองที่ต้องการลบจริง
กรณี Storage ลบภาพไม่สำเร็จ ระบบแจ้งให้ทราบ แต่ออเดอร์และยอดขายถูกลบแล้ว

## การตรวจสอบ

ทดสอบ Build และ TypeScript ของชุดต้นฉบับ Vercel/Supabase ผ่านแล้ว
ทดสอบ PostgreSQL: เจ้าของ/สิทธิ์ Origin เลขยืนยัน rollback เอกสาร สลิป และยอด VAT
ยังไม่ได้ทดสอบหรือ Deploy ในบัญชี Vercel/Supabase ของคุณ
