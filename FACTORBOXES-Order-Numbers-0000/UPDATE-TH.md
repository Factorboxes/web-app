# อัปเดตซ่อนหลังบ้าน + เลขออเดอร์ 0000

สำหรับเว็บ FACTORBOXES บน GitHub / Vercel / Supabase
ชุดนี้ยังไม่ได้ Deploy ไปบัญชีของคุณ และรวมปุ่มลบออเดอร์จากชุดก่อนหน้าแล้ว

## ทำตามลำดับ

1. แตก ZIP นี้
2. เปิด Supabase ของเว็บ > SQL Editor > New query
3. เปิด supabase/04-order-numbers.sql คัดลอกทั้งหมด แล้วกด Run
4. SQL เพิ่มเลขออเดอร์ โดยเก็บสินค้า สมาชิก ออเดอร์ และยอดเงินเดิมไว้
5. เปิด GitHub repository ของเว็บ (จากข้อมูลก่อนหน้า Factorboxes/web-app)
6. อัปโหลดไฟล์ใน app และ lib ไปตำแหน่งเดิมใน repository แล้ว Commit changes
7. โฟลเดอร์ต้องรวมกับของเดิม เช่น app/shared.tsx ไม่ใช่ app/app/shared.tsx
8. รอ Vercel Deploy สำเร็จ แล้วรีเฟรชหน้าเว็บ
9. ทดสอบสร้างออเดอร์และดูเลขในหลังบ้าน/ประวัติสมาชิก

ต้องรัน SQL ก่อนอัปโหลดโค้ด มิฉะนั้น API จะหา order_no ไม่พบ
ห้ามรันไฟล์สร้างฐานข้อมูลหรือ seed เดิมซ้ำเพื่อรีเซ็ตออเดอร์
ถ้าไฟล์ใดเคยแก้เพิ่มเติมหลังจากชุดต้นฉบับ ให้ตรวจ diff และเก็บการแก้นั้นก่อนแทนที่

## การทำงาน

- ไม่มีลิงก์หลังบ้านบนเมนู ท้ายเว็บ หรือหน้าเข้าสู่ระบบ
- เข้าหลังบ้านโดยพิมพ์ https://ชื่อเว็บของคุณ/admin และใช้บัญชีแอดมินเดิม
- ออเดอร์ที่มีอยู่ก่อนอัปเดตได้รับเลขจากเก่าไปใหม่: 0000, 0001, 0002…
- ถ้าไม่มีออเดอร์เดิม ออเดอร์แรกที่สร้างหลังอัปเดตจะเป็น 0000
- เมื่อเกิน 9999 จะเป็น 10000 เป็นต้นไป
- ใช้ sequence ใน PostgreSQL เพื่อป้องกันเลขซ้ำเมื่อสั่งพร้อมกัน
- ลบออเดอร์แล้วไม่ย้อนเลข และไม่ใช้เลขเดิมซ้ำ
- อาจมีเลขข้ามเมื่อรายการถูกลบหรือการบันทึกล้มเหลว ไม่ได้จัดเลขใหม่ให้แน่นทุกครั้ง
- รายได้และ VAT ไม่เปลี่ยนจากการเปลี่ยนเลข
- ลิงก์ติดตามและสิทธิ์สมาชิกยังอ้างอิงรหัสลับเดิม ไม่เปิดให้ค้นข้อมูลลูกค้าด้วยเลขลำดับ
- เอกสารเก่าที่ออกไปแล้วคงเลขอ้างอิงที่บันทึกในเอกสารไว้ เอกสารออกใหม่ใช้เลขใหม่
- ปุ่มลบออเดอร์ใช้เลขใหม่ในการยืนยัน และใช้ได้เฉพาะเจ้าของร้าน
