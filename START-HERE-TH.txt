02 ติดต่อเรา: โทรศัพท์ / LINE / Facebook
03 ใบราคากล่องไปรษณีย์

เปลี่ยนลำดับเมนูลัดด้านบนให้ตรงกับเนื้อหา
ข้อมูลเบอร์โทร LINE และ Facebook ใช้ค่าที่บันทึกในหลังบ้าน
ลิงก์เดิม #install, #contact และ #prices ใช้งานต่อได้

วิธีอัปโหลด GitHub
1. แตกไฟล์ factorboxes-contact-section-02-update.zip
2. เปิด Repository Factorboxes/web-app สาขา main
3. ที่หน้าแรกของ Repository เลือก Add file > Upload files
4. ลากโฟลเดอร์ app จากไฟล์ที่แตกแล้วลงไป ตรวจให้ได้เส้นทาง:
   app/guide/screen.tsx
   app/guide/guide.css
5. กด Commit changes แล้วรอ Vercel Deploy จนขึ้น Ready
6. เปิด https://www.factorboxes.com/ แล้วรีเฟรชหน้า
   ตรวจว่าช่องทางติดต่ออยู่หลังติดตั้งแอป และก่อนใบราคา
   ลองกดเมนูลัด “ติดต่อเรา” และ “ใบราคา”

หากอัปโหลดด้วยมือถือและเลือกโฟลเดอร์ไม่ได้:
เข้าไฟล์ app/guide/screen.tsx ใน GitHub แล้วกดแก้ไข วางเนื้อหาจากไฟล์ชื่อเดียวกัน
ทำเช่นเดียวกันกับ app/guide/guide.css แล้วบันทึก
