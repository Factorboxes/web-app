FACTORBOXES — แก้ใบราคาขนาดใหญ่ให้มีปุ่มปิด
วันที่จัดทำ: 17 ตุลาคม 2569

สิ่งที่แก้
- แตะรูปใบราคา หรือ “ดูภาพใหญ่” จะเปิดหน้าดูภาพภายในเว็บ
- มีปุ่ม “× ปิด / กลับหน้าเดิม” อยู่ด้านบนเสมอ
- ใช้สองนิ้วหรือปุ่ม + / − เพื่อขยาย–ย่อภาพได้ 100–400%
- เลื่อนดูภาพหลังขยาย และกด “พอดีจอ” เพื่อกลับขนาดเริ่มต้น
- ปิดแล้วกลับมาที่ตำแหน่งเดิมในหน้าแรก
- บนคอมพิวเตอร์ กด Escape เพื่อปิดได้
- เมื่อโหลดรูปไม่สำเร็จ ยังมีปุ่มปิดให้กลับหน้าเดิม

วิธีอัปโหลด GitHub และ Vercel
1. แตกไฟล์ factorboxes-price-list-close-button-fix.zip
2. เข้า Repository Factorboxes/web-app สาขา main
3. ที่หน้าแรก Repository กด Add file > Upload files
4. ลากโฟลเดอร์ app จากชุดนี้เข้าไปทั้งโฟลเดอร์
5. ตรวจว่ามีทั้ง 3 เส้นทางข้างต้น แล้วกด Commit changes พร้อมกัน
   ต้องมีไฟล์ใหม่ทั้งสองไฟล์ด้วย จึงจะ Build ได้ครบ
6. รอ Vercel Deploy จนขึ้น Ready
7. เปิด https://www.factorboxes.com/ แล้วรีเฟรชหน้าแรก
8. เลื่อนไปข้อ 03 ใบราคา แตะรูป ลองขยาย แล้วกดปุ่มปิดด้านบน
   หน้า /guide ใช้หน้าดูภาพเดียวกัน

หากกำลังค้างอยู่ในไฟล์รูปแบบเก่า:
ให้เปิดลิงก์ https://www.factorboxes.com/ ใหม่ก่อน แล้วทดสอบจากรูปบนหน้าแรก

ชุดนี้ไม่ต้องรัน SQL หรือเพิ่ม Environment Variables และไม่มีแพ็กเกจใหม่ที่ต้องติดตั้ง
ภาพใบราคาใช้ไฟล์เดิมใน public/price-lists/factorboxes-price-list.jpg

การตรวจสอบ
- ผ่านการตรวจ TypeScript แบบ strict ของหน้าดูภาพใหม่
- บันเดิลหน้าจริงที่แก้ไขพร้อมหน้าดูภาพใหม่ โดยจำลองข้อมูลแบรนด์และส่วนแจ้งเตือนสำหรับตรวจในเครื่อง
- ผ่านการตรวจใน Chromium: 360×800, 430×932, 932×430 และ 1440×1000
- ตรวจการเปิดจากรูปและปุ่มดูภาพใหญ่, ปิดแล้วคืนตำแหน่งและโฟกัส,
  ขยายและเลื่อนโดยปุ่มปิดยังอยู่บนจอ, สองนิ้วซูมเฉพาะภาพ,
  พอดีจอ, Escape และปิดเมื่อรูปโหลดผิดพลาด
- ยังไม่ได้ทดสอบบน iPhone/Safari จริง หรือรัน Build ของเว็บไซต์ทั้งโครงการ
- ยังไม่ได้อัปโหลด GitHub หรือ Deploy เว็บจริง
