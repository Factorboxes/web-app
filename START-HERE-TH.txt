FACTORBOXES — เพิ่มใบราคาส่งในหัวข้อ 03
วันที่ 19 ตุลาคม 2569

เพิ่มใบราคาส่งต่อจากใบราคาส่งฟรีเดิม ภายในหัวข้อ 03
มีปุ่มดาวน์โหลด เปิดภาพใหญ่ ขยาย–ย่อ และปิดกลับหน้าเดิมทั้งสองใบ
ใช้ภาพราคาส่งที่คุณส่งมาโดยไม่แก้ไขราคา
แสดงเงื่อนไขสั่งเต็มคันรถกระบะ สำหรับกรุงเทพฯ ปริมณฑล และจังหวัดใกล้เคียง
ปุ่มสั่งซื้อราคาส่งพาไปช่องทางติดต่อร้าน
ชุดนี้เพิ่มใบราคาแสดงผล ไม่เปลี่ยนราคาสินค้าในตะกร้าหรือฐานข้อมูล

วิธีติดตั้ง
1. แตก ZIP นี้
2. เปิด GitHub Repository Factorboxes/web-app สาขา main
3. จากหน้าแรก Repository เลือก Add file > Upload files
4. ลากโฟลเดอร์ app และ public จาก ZIP เข้าไป แล้ว Commit changes พร้อมกัน
5. รอ Vercel Deploy ขึ้น Ready แล้วรีเฟรชหน้าแรก
6. ไปหัวข้อ 03 จะพบใบราคาส่งต่อจากใบราคาเดิม
7. ทดลองเปิดภาพใหญ่ของทั้งสองใบ กดขยาย แล้วปิดกลับหน้าเดิม
   ตรวจปุ่มดาวน์โหลดว่าได้ภาพตรงกับใบราคาที่เลือก
