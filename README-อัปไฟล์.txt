# FACTORBOXES — แก้สร้าง CODE ได้หลายรายการ

ชุดนี้แก้ปัญหาหน้า CODE ที่เหมือนสร้างได้เพียง 1 รายการ โดยแยกคำสั่ง “สร้างใหม่” ออกจาก “แก้ไข” ชัดเจน

ไฟล์ที่ต้องอัปขึ้น GitHub มี 2 ไฟล์:
1. `app/admin/coupons.tsx`
2. `app/api/coupons/route.ts`

วิธีอัป:
- เข้า GitHub repository `Factorboxes/web-app`
- เปิดโฟลเดอร์ตาม path ข้างต้น
- Replace ไฟล์เดิมด้วยไฟล์ในชุดนี้
- Commit changes
- รอ Vercel Deploy ขึ้นสถานะ Ready
- เข้า `/admin` > CODE ส่วนลด แล้วกด Refresh
- สร้าง CODE ตัวที่ 2 ด้วย “รหัสใหม่” เช่น `APP3` หรือรหัสที่ต้องการ

ไม่ต้องรัน SQL เพิ่มสำหรับแพตช์นี้ ถ้า `18-coupon-quotas.sql` เคยรันสำเร็จแล้ว

สิ่งที่แก้:
- Create ใช้ `INSERT` ใหม่จริง ไม่ใช้ upsert ทับรายการเดิม
- Edit ใช้ `UPDATE` แยกต่างหาก
- ตรวจ CODE ซ้ำก่อนสร้าง
- หลังสร้างจะตรวจว่าบันทึกลงฐานข้อมูลแล้วจริง
- โหลดรายการใหม่แบบ no-cache
- หลังสร้างสำเร็จ ฟอร์มล้างทันที พร้อมสร้าง CODE ถัดไป
